# Requerimientos del Sistema - Biblioteca
## Descripción del Modelo
El sistema gestiona el inventario de libros, autores, editoriales y el registro de préstamos a estudiantes universitarios a través de funcionarios de los campus.

## Requerimientos Funcionales
- RF1: Registrar y catalogar libros por tipo, autor y editorial.
- RF2: Registrar estudiantes vinculados a una carrera y campus universitario.
- RF3: Gestionar el préstamo y devolución de libros.
- RF4: Auditar automáticamente cada nuevo préstamo registrado.

## Requerimientos No Funcionales
- RNF1: Integridad referencial mediante claves foráneas y restricciones ON DELETE / ON UPDATE.
- RNF2: Seguridad de acceso mediante roles de usuarios con permisos específicos.
